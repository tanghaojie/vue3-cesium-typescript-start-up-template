# Geo 拍摄模块与逐帧输出

> 来源规范快照：Cyber-Sight 9697230d7278ae88afb3c82c98e3865181847d08。此文保留来源的功能语义与制作约定；独立应用的当前目录、依赖和部署以 [Geo application design](../../design/geo-workbench.md) 为准。未声明目标浏览器验收通过。

## 目标与边界

为「AI建模世界」增加独立“拍摄”任务入口，提供可复用镜头工程、建筑模板、关键机位、按秒预览、净画面以及固定分辨率逐帧 MP4 / PNG 序列输出。全部属于 Platform Geo 内部插件，不增加后端、数据库、模型托管或 Foundation 修改。模型仍从既有外部数据入口加载；工程保存资源 URL 与定位信息，不自动执行导入文件中的远程地址。

## 职责、公共端口与依赖

- `plugins/capture/`：插件注册、响应式控制器、拍摄面板与净画面控制浮层。
- `tools/capture/capture-project.ts`：版本化工程、运行时校验、模板、局部米制机位、镜头求值和输出尺寸；不依赖 Vue。
- `tools/capture/capture-session.ts`：独占相机/时间、模型动画、场景状态快照与恢复；向预览和导出提供同一 `apply(seconds, shotId?)`，可选镜头 ID 仅用于端点定位，普通播放与导出按时间切镜。
- `tools/capture/capture-export.ts`：预热、逐帧渲染、加载稳定检查、画面采集、编码、下载、取消与恢复。
- `plugins/data/data.capabilities.ts` 登记 `data.captureSubjects`：只读主体中心/半径/来源/动画清单、动画外部采样租约、可见瓦片加载状态；不暴露资源 Map 或模型私有属性。独立模型等待纹理一起就绪，防止拍到分批贴图过程。
- `tools/model/model-animation.ts` 新增外部采样租约：暂停自身 RAF、按绝对秒数求值，释放时恢复原片段/进度/速度/循环/播放状态。普通动画操作在租约期间拒绝抢占。
- 通用工作台展示端口由 Geo core 提供，只描述净画面与画幅；页面不导入拍摄业务 controller。
- 编码依赖 Mediabunny（浏览器原生 WebCodecs + MP4 封装），PNG ZIP 使用 fflate。大文件在 File System Access 可用时流式写盘，否则使用有明确内存上限的下载缓冲。

依赖方向为页面组装 → 插件 → 工具；拍摄通过 capability 消费 Data / Scene 公共端口。移除拍摄插件只需删除注册项、任务元数据及拍摄文件。

## 工程与镜头

版本 1 工程包含名称、主体来源与地理锚点、横/竖画幅、1080p/4K、帧率、场景起始 UTC、独立镜头首尾静止余量、镜头数组。镜头包含稳定 ID、名称、时长、类型、起止机位、每拍摄秒对应的场景秒数和可选模型片段/局部秒数范围。机位为主体 ENU 局部坐标中的位置与注视点、默认固定且可精调的起止视场角；机位捕获可从真实相机取得。模板区分高楼、宽体建筑与建筑群，提供环绕、推进、升降、横移、固定机位昼夜、机位过渡与拼装展示。前三种模板从所在地太阳时约 14 时开始，日夜镜头推进至约 22 时；日期可编辑，不保证极区日落。切镜是明确边界，镜头内使用五次平滑插值或匀速，环绕采用角度连续的圆弧。

工程可自动保存至版本化 localStorage，也可 JSON 导入/导出；显式工程库最多 20 项。所有导入字段、数量、数值、时间和尺寸均校验；损坏存储不覆盖可用工程。导入工程尝试匹配同 URL 与同位置的已加载主体，否则必须重新绑定，资源缺失时明确提示。绑定其他建筑时相对机位按主体半径缩放，动画引用清除。横竖画幅单独计算模板取景，已有镜头切画幅后需预览/调整或重建模板，不自动重写人工机位；不宣称自动避障。

点击分镜名称选择镜头，参数编辑器位于整个分镜列表下方。上移、下移和复制按钮在 hover 或键盘 focus 时显示蓝色反馈，删除显示红色反馈；按钮保持独立间距。样式反馈不增加删除确认或改变原有操作语义。

分镜编辑提供起点、终点的相机距离（米），定义为相机至该机位注视点的直线距离。缩短距离可拉近模板镜头；修改沿原视线移动相机，保留注视点、观察方向与视场角，校验有限数值及至少 0.1 米的间距。固定机位只编辑起点距离，终点显示同一距离。距离从已有机位坐标派生并写回坐标，不新增重复存储字段，版本 1 工程及已有人工机位保持兼容。修改成功后定位到对应端点，便于继续调整构图；不自动修改模板默认取景或执行避障。

每个分镜卡片和当前编辑器均提供“移动到起点视角”“移动到终点视角”。按钮选中对应镜头、暂停播放并按该镜头的精确 0 / duration 秒求值，同时采样累计场景时间与模型动画，保持相机可手动拖动。环绕终点使用起点角度加环绕角度后的实际机位，固定机位两端视角相同。端点定位显式传入镜头 ID，避免非末尾镜头的终点恰好落入下一镜头；普通进度条、播放与输出保留原切镜语义。定位复用可恢复拍摄会话，停止、Esc 和离开面板仍恢复进入预览前的状态，输出期间禁止编辑与定位。

## 时间、预览与生命周期

拍摄进度是局部秒数，不新增 Cesium Clock。每次求值独立计算相机、模型片段与唯一 `viewer.clock.currentTime`；场景 `shouldAnimate=false`，不会把昼夜倍率乘给相机。预览用真实时间驱动局部秒数，暂停/跳转与离线导出调用同一求值函数。模型片段只对当前带动画资源生效；拼装模板扩大取景，但任意模型飞入边界仍需人工确认。

会话取得时取消现有飞行和交互，保存相机 transform/position/direction/up、视场角、Clock 时间/倍率/播放/步进状态、输入、质量与所借动画。停止、结束、切换主体、后台、取消、插件卸载、上下文丢失和异常均结束会话并恢复可恢复状态。被移除的模型不再访问。净画面保留退出/停止控件，Esc 恢复工作台；导出取消等待当前写入结束后恢复。

## 逐帧输出

整片帧数为 `round(duration × fps)`，第 n 帧绝对时间为 `n / fps`，时间戳使用微秒且单调，帧持续时间以相邻时间戳之差计算。单镜头/逐镜头批次各加可配置 0–5 秒首尾静止余量（默认各 0.5 秒），按含余量时长独立取整；静止余量钳制在该镜头起止范围，不进入相邻镜头。整片无额外余量，切镜不重复尾帧。批次按编号和镜头名分别输出。

导出期间关闭 Viewer 默认循环，通过 `scene.renderQuality.acquireFixedResolution` 暂停自适应并锁定真实绘图像素，保留当前画质与手动光照/阴影；设置专用画幅后调用公开 resize/render，按固定时间反复渲染预热。相机移动后的 Globe / 可见 3D Tiles 要连续 3 步达到加载稳定条件，首帧及切镜至少 16 步，才同步复制 WebGL canvas，失败或单帧前台等待超过 30 秒时中止并提示。后台等待不计入加载超时；取消通知编码器并等待写入释放。动态环境图等 GPU 内部渐进计算经过预热，但不承诺跨设备逐像素一致。

导出尺寸由实际 Cesium canvas 的临时 CSS 宽高固定，不改写 Vue 管理的工作台容器样式，避免预览画幅的响应式更新与导出争用同一尺寸。固定分辨率租约使 DPR 不参与输出尺寸计算，逐步渲染前调用公开 `viewer.resize()`；采集前同时核对 canvas 像素尺寸与 Scene 绘图缓冲尺寸。实际无法分配目标尺寸时报告目标、画布和绘图缓冲的宽高，保持严格校验，不把低分辨率画面拉伸为目标尺寸。完成、取消或异常均恢复 canvas 原样式和浏览分辨率。

MP4 在开始前检查编码支持，按帧等待编码背压；PNG 使用编号文件与拍摄 JSON/合成说明的 ZIP。通过逐帧 canvas 快照避免 WebGL 默认绘图缓冲在异步等待时被清空。File System Access 支持时从用户点击事件选择文件并流式输出；不支持时缓冲有上限，超出中止，不持续堆积无界帧。中止写盘时 abort，不发布貌似成功的部分成品；已完成的批次文件保留。

## 验证与失败模式

遵守 AGENTS.md，不创建或运行前端单元/组件/浏览器自动化测试。执行格式、Vue/TypeScript、相关 ESLint、生产构建、架构与文档归档 CI。人工验收涵盖：高楼/宽体、横竖屏、机位捕获与编辑、模板/排序/删除、保存/导入/损坏输入、暂停/回退、昼夜与拼装同步、净画面/Esc、1080p/4K、帧数/时长/首尾帧、单镜头/批次、编码不支持、加载超时、跨域采集错误、取消/后台/路由离开、状态恢复及长片内存。

实际 GPU、浏览器编码和视频视觉由维护者人工验收；工程检查不替代这些结论。

## 与目录模式及精细度的集成

2026-10-19 合并 origin/master 的模式/精细度更新：目录按显式发布配置选择静态、飞入或爆炸与对应精细度，再由原 Data 路径创建独立 Model。拍摄从 `data.captureSubjects` 消费已加载主体与其内嵌片段，不复制目录选择状态或推断动画文件名。不同模式/精细度替换模型组后，拍摄工程需绑定当前加载主体；旧普通播放与拍摄接管边界保持有效。

# AI建模世界拍摄指南

> 来源规范快照：Cyber-Sight 9697230d7278ae88afb3c82c98e3865181847d08。此文保留来源的功能语义与制作约定；独立应用的当前目录、依赖和部署以 [Geo application design](../design/geo-workbench.md) 为准。未声明目标浏览器验收通过。

## 第一条视频

1. 在 Geo 的“外部数据”加载建筑模型。需要拼装时在 AI 模型目录选择已发布的“飞入拼装”模式，或直接加载带内嵌动画的 GLB；目录只提供配置明确声明的模式和精细度，不猜测旁边文件。
2. 打开左侧“拍摄”，刷新模型并选择拍摄主体。
3. 选择横屏/竖屏、1080p/4K 和帧率。初次建议 1080p、30 fps。
4. 选择高楼、宽体建筑、建筑群或拼装模板，点击“生成分镜”。前三种模板从建筑所在地太阳时约 14 时开始，日夜镜头推进 8 小时；日期仍可修改。生成会替换镜头，先保存需要保留的工程。
5. 播放或拖动进度，检查建筑出框、遮挡、穿地和飞入构件范围。暂停后可拖动场景，把当前视角设为选中镜头的起点或终点。环绕角度由起点计算，终点调节距离、高度与注视点；“查看路径”辅助检查，不自动避障。
6. “保存到本机”加入工程库；“导出工程”保留 JSON 备份。工程包含模型 URL、定位和相对机位，不包含 GLB、影像或视频。导入只恢复配置，不自动访问模型地址；重新加载资源后绑定主体。
7. 先选择“当前镜头”试拍。确认后输出完整工程，或按镜头批次输出独立素材。

## 时间与动画

- 镜头时长始终是视频秒数。柔和起止使用连续速度曲线；匀速适合连续环绕。
- 昼夜速度 0 锁定光照，3600 表示拍摄一秒推进一小时；负值倒退日期。前一个镜头推进的场景时间会延续至下一个镜头。
- 模型动画可指定片段起止秒数，等值可保持某一帧，起点大于终点可倒放；未指定时保持此前片段姿态。拖动拍摄进度会重新求值，不依赖播放历史。
- 拍摄支持内嵌节点 TRS 动画，包括本项目建筑拼装规范；不支持形态权重通道的统一采样。普通模型播放器保持独立行为。
- 停止、结束、Esc 或离开页面会归还相机、时间和动画。预览进入后台停止并保留进度；逐帧导出等待回到前台后继续。

## 导出

- MP4 使用浏览器 H.264 编码；开始前检查实际尺寸和帧率支持。不能编码时降低尺寸/帧率，或使用 PNG ZIP。
- PNG ZIP 包含 `frame-000000.png` 起的连续编号、工程与导出范围 JSON、FFmpeg 合成命令。无需原生视频编码器。
- 单镜头与逐镜头批次默认在首尾各保留 0.5 秒静止余量，方便后期卡点；可以设置为 0–5 秒。整片不追加余量。
- File System Access 可用时，单文件选择保存位置，批次选择目录，按背压流式写盘；普通浏览器以下载方式输出，单文件缓冲上限 256 MB，批次可能要求允许多个下载。
- 每帧等待地形/影像与可见瓦片连续稳定后采集；首帧和切镜增加预热。单帧前台加载超过 30 秒会中止，可隐藏失败资源或检查网络后重试。
- 导出使用当前场景画质和光照，锁定指定绘图像素，不临时重置用户的阴影或其他手动设置。希望使用最高场景质量时先到“场景”选择性能档。
- 导出只采集三维画布，附可读来源文字；工作台、进度条、拍摄控制和路径不进入视频。画面内没有旁白或音乐，后期用剪辑软件添加。
- 总帧数为时长（含适用的首尾余量）乘帧率后四舍五入，视频实际时长为帧数除帧率。多个镜头各自输出时分别取整。渲染慢会增加导出耗时，不改变视频播放速度。
- 取消时中止当前写入，不把未完成文件当成成功结果；此前完成的批次文件保留。跨域采集、编码器故障、GPU 上下文丢失或加载超时会显示错误并恢复工作台。

## 人工验收清单

本次按仓库规则只执行工程检查。请分别使用静态高楼、宽体建筑和动画 GLB，验收横竖屏、画幅、机位、排序、JSON/本机保存、倒退跳转、日夜/拼装同步、净画面与路径，以及单镜头/整片/批次导出。核对输出尺寸、帧数、时长、第一帧和最后一帧，检查取消、后台、网络失败和退出后的恢复。4K/60 fps 由实际浏览器、编码器与 GPU 能力决定；GPU 渐进光照不承诺跨设备逐像素一致。

实现边界见[拍摄模块设计](../reference/source-design/geo-capture.md)。

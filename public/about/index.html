01 / CAPABILITIES

从数据，到场景，再到镜头。

既可以直接在线探索，也可以克隆源码，把已有空间能力作为二次开发的起点。

01

数据与三维内容

加载 GeoJSON、glTF/GLB、3D Tiles，配置影像与地形，通过 URL 或 AIModels 静态模型目录组织场景。

02

空间观察与分析

使用绘制、距离与面积测量、模型工具、地形分析和对比视图；调整场景模式、质量、光照与时间。

03

相机编排与输出

编辑机位与镜头，使用仿真时间轴预览运镜，逐帧输出 MP4 或 PNG 序列，并以 JSON 保存、导入拍摄工程。

02 / GET STARTED

先打开，再动手。

在线工作台默认进入中文，英文可使用 ?lang=en-US。交互建议使用启用 WebGL 与硬件加速的桌面浏览器，最低布局验收基线为 1280 × 720。

打开工作台 ↗
本地开发~/cesium-workbench 
git clone https://github.com/tanghaojie/Cesium-Workbench.git
cd Cesium-Workbench
corepack enable
corepack prepare pnpm@11.22.0 --activate
pnpm install --frozen-lockfile
pnpm dev

需要 Node.js 22.12+ 与 pnpm 11.22.0。构建输出为 dist，部署在站点根路径。

03 / PROJECT FACTS

关于这个项目，先了解这些。

旧模板去哪了？

GitHub 仓库已从 vue3-cesium-typescript-start-up-template 更名为 Cesium-Workbench。旧名称指向同一项目，原模板实现保存在 1.0.0 分支和 1.0.0 标签。当前 2.0.0-rc.1 是从 Cyber-Sight Geo 提取的独立工作台。

适合用来做什么？

适合三维地理数据浏览、模型与场景演示、空间工具实验，以及相机镜头和可视化视频的制作。开发者也可以把它作为 Vue 3 + TypeScript + CesiumJS 项目的起点。

AIModels 会生成三维模型吗？

AIModels 是可加载资产的静态模型目录；本应用没有内置三维模型生成服务。航班示例使用模拟数据。

可以直接商用或在手机上使用吗？

源码采用 MIT 许可，远程示例模型、影像和地形各有自己的使用条款。工作台主要面向桌面横向布局；浏览器、设备、编码器、网络与资源 CORS 会影响加载和视频输出。

源码应该提交到哪里？

开发与问题反馈使用 个人源仓库；组织仓库用于同步源码和发布官网。两者属于同一个项目的开发与发布流程。

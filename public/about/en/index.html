01 / CAPABILITIES

From data to scenes to camera shots.

Explore the online application, or clone the source to use its spatial capabilities as a starting point for your own project.

01

Data and 3D content

Load GeoJSON, glTF/GLB and 3D Tiles, configure imagery and terrain, and organize scenes using URLs or the AIModels static model catalog.

02

Spatial exploration

Use drawing, distance and area measurement, model tools, terrain analysis and comparison views. Control scene mode, quality, lighting and time.

03

Camera shots and exports

Edit camera positions and shots, preview motion on a simulation timeline, export MP4 or PNG sequences frame by frame, and save or import capture projects as JSON.

02 / GET STARTED

Open it. Then make it yours.

The workbench defaults to Chinese; use ?lang=en-US for English. Use a desktop browser with JavaScript, WebGL and hardware acceleration. The minimum interaction acceptance viewport is 1280 × 720.

Open workbench ↗
Local development~/cesium-workbench 
git clone https://github.com/tanghaojie/Cesium-Workbench.git
cd Cesium-Workbench
corepack enable
corepack prepare pnpm@11.22.0 --activate
pnpm install --frozen-lockfile
pnpm dev

Requires Node.js 22.12+ and pnpm 11.22.0. Build output is dist and requires deployment at the site root.

03 / PROJECT FACTS

A few things to know.

What happened to the original template?

The repository was renamed from vue3-cesium-typescript-start-up-template to Cesium-Workbench. The former name refers to the same project. The original template is preserved on branch 1.0.0 and tag 1.0.0. The current 2.0.0-rc.1 workbench was extracted from Cyber-Sight Geo.

What is it useful for?

Explore 3D geospatial data, demonstrate models and scenes, experiment with spatial tools, and create camera-shot visualizations. Developers can also use it as a starting point for Vue 3, TypeScript and CesiumJS applications.

Does AIModels generate 3D models?

AIModels is a static catalog of loadable model assets. There is no built-in 3D generation service. The flight example uses simulated data.

Can I use it commercially or on mobile?

Source code is MIT-licensed; remote models, imagery and terrain have separate terms. The workbench targets a desktop landscape layout. Browser, device, encoder, network and resource CORS constraints affect loading and video output.

Where should contributions go?

Use the personal source repository for development and issues. The organization repository mirrors source and publishes this website; both belong to the same project workflow.
